Atlas Privacy Policy

Last updated: 19 October 2026.

Atlas is a private tool that is used only by its owner, Diego Guevara. It asks for access to the owner's own Google Drive, Google Docs and Google Sheets so that it can read and create files for the owner.

What data is accessed

Only files in the owner's own Google account, and only when the owner asks Atlas to work on them.

How data is used and stored

Data is used only to complete the owner's requests. It is not sold, shared with other people or companies, or used for advertising. Access tokens are stored on the owner's own computer in an encrypted secrets vault.

Google user data

Atlas's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke Atlas's access at any time at myaccount.google.com/permissions.
